# Contributing Guidelines

Thanks for taking an interest in this project!

This is primarily a personal project, but bug reports, suggestions, and pull requests are welcome.

## How to Contribute

1. **Issues:** If you find a bug or have a feature idea, feel free to open an issue using the provided templates.
2. **Pull Requests:** 
   - Before submitting large changes, please open an issue first to discuss what you'd like to change.
   - Ensure backend tests pass (`go test ./...`) and the frontend builds cleanly (`pnpm build`).
   - Fill out the PR template when submitting your code.

Thank you for helping improve the project!
