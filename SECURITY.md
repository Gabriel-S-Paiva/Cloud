| Version | Supported          |
| ------- | ------------------ |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please **do not open a public issue**.

Instead, report it privately using GitHub's built-in feature:
1. Go to the **Security** tab of this repository.
2. Click **Report a vulnerability** under *Vulnerability reporting*.

Your report will be handled confidentially, and we will acknowledge receipt as soon as possible.
